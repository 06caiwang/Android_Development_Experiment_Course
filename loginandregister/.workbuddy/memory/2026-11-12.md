# 2026-11-12

## 登录注册 App — 需求与方案讨论（已完成，待开工）

项目现状：Android Studio 空模板，Java + AppCompat + Material 1.9.0，minSdk 24 / compileSdk 34，仅 MainActivity + 空布局，无任何第三方依赖。

### 已确认的技术决策
- 数据存储：本地 SQLite（SQLiteOpenHelper 手写，不引 Room）
- 登录方式：手机号 / 邮箱 / QQ 三选一，顶部 segmented tabs 切换
- QQ 登录：本地模拟授权（真实 SDK 需 AppID），首次授权自动建号，账号格式 `qq_xxx`
- 验证码：本地生成 6 位数字，Toast 显示 + 60s 倒计时
- 页面结构：两个 Activity（LoginActivity + RegisterActivity），登录成功进 MainActivity 并清空返回栈
- 密码存储：SHA-256 + 随机 salt，不存明文

### 界面方案
- 视觉：Material3 紫色系 (#6750A4) 主色，圆角 10dp 输入框，聚焦时描边变主色
- 登录页：Logo → 标题 → 三 tab → 字段 → 记住登录/忘记密码 → 登录按钮 → 注册链接
- 注册页：返回 → 创建账号 → 手机号/邮箱 tab → 账号 → 验证码+倒计时 → 密码(强度条) → 确认密码 → 协议勾选(未勾选时按钮置灰) → 注册按钮
- 图标：全部手写 VectorDrawable（ic_phone / ic_email / ic_qq 企鹅 / ic_eye / ic_eye_off / ic_lock / ic_back），QQ 用品牌蓝 #12B7F5

### 计划文件结构
- activity: LoginActivity / RegisterActivity / MainActivity
- db: UserDbHelper（users 表：id, account, account_type, nickname, avatar, password_hash, salt, created_at, last_login_at）
- util: PasswordUtils（哈希）、Validator（手机号/邮箱/密码正则）、SessionManager（SharedPreferences 登录态）
- model: User
