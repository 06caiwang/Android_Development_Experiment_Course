### 程序3 — 4. 逻辑：读取并校验输入（`MainActivity.java` 第 83–94 行）

```java
/** 读取输入：空输入按 0 处理，非法内容返回 null。 */
private Long readInteger(EditText field) {
    String raw = field.getText().toString().trim();
    if (raw.isEmpty()) {
        return 0L;
    }
    try {
        return Long.parseLong(raw);      // 字符串 → 长整型
    } catch (NumberFormatException e) {
        return null;                     // 只有一个"-"这类非法输入
    }
}
```

### 程序3 — 5. ★最核心：计算并显示到界面（`MainActivity.java` 第 97–123 行）

```java
/** 计算并刷新界面。 */
private void calculate() {
    // ① 取出两个整数
    Long a = readInteger(etFirst);
    if (a == null) {
        reportInvalid(etFirst);          // 提示"请输入合法的整数"并抖动输入框
        return;
    }
    Long b = readInteger(etSecond);
    if (b == null) {
        reportInvalid(etSecond);
        return;
    }

    // ② 相加（addExact 在溢出时抛异常，避免显示错误结果）
    long sum;
    try {
        sum = Math.addExact(a, b);
    } catch (ArithmeticException overflow) {
        Toast.makeText(this, R.string.toast_overflow, Toast.LENGTH_SHORT).show();
        shake(tvResult);
        return;
    }

    // ③ 把结果写回界面 —— 本作业要求的关键一步
    tvResult.setText(String.valueOf(sum));
    tvExpression.setText(buildExpression(a, b) + " =");
    playResultAnimation();               // 结果数字弹入动画
    hideKeyboard();                      // 收起软键盘
}
```

**这段就是作业要求的兑现处**：`a`、`b` 相加得到 `sum`，再用 `tvResult.setText(String.valueOf(sum))` 把结果输出到界面上。

### 程序3 — 6.（加分项）负数算式更自然（`MainActivity.java` 第 125–134 行）

```java
/** 拼出 "12 + 30"、"12 − 30" 这种可读的算式。 */
private String buildExpression(long a, long b) {
    if (b < 0 && b != Long.MIN_VALUE) {
        return a + " − " + (-b);         // 5 + (-3) → 显示 5 − 3
    }
    if (b < 0) {
        return a + " + (" + b + ")";
    }
    return a + " + " + b;
}
```

### 程序3 — 7.（加分项）结果弹入动画（`MainActivity.java` 第 136–149 行）

```java
private void playResultAnimation() {
    tvResult.animate().cancel();
    tvResult.setScaleX(0.86f);
    tvResult.setScaleY(0.86f);
    tvResult.setAlpha(0f);
    tvResult.animate()
            .scaleX(1f).scaleY(1f).alpha(1f)
            .setDuration(360)
            .setInterpolator(new OvershootInterpolator(1.6f))
            .start();
}
```

## 五、答辩/抽查可能问到的 3 个问题

1. **结果是怎么显示到界面上的？** → `findViewById(R.id.tvResult)` 拿到 TextView，调用 `setText()` 更新文本，主线程直接改 UI。
2. **为什么用 `Long.parseLong` 而不直接 `Integer.parseInt`？** → 支持更大的整数范围，配合 `Math.addExact` 还能检测溢出。
3. **`@+id/tvResult` 里的 `+` 是什么？** → 首次声明时向 `R.java` 注册新 id；引用时写 `@id/tvResult`。
