## 程序1：TableLayout 实现计算器界面（对应要求第 1 条）

**为什么这段是核心**：题目原文就是"使用 TableLayout 实现一个简单的计算器界面"，所以 `TableLayout` 这一段是本次作业的硬性得分点，必须完整出现。

**★ 三个关键技术点（报告里要写出来，光贴代码不给分）**

1. `stretchColumns="*"` + 子按键 `layout_width=0dp`、`layout_weight=1` → 四列**严格等宽**
2. `TableRow` 的行高交给按键的固定 `62dp`，**不要**给 TableRow 写 `0dp + weight`（TableLayout 自己测量行高，权重在 UNSPECIFIED 下会算成 0，整行按键会消失）

## 程序3：按键输入状态机 `CalcEngine.java`

**为什么是核心**：界面只是壳，真正的"计算器行为"都在这里——每个键按下去表达式怎么变、什么时候开始新算式、除零怎么提示。报告里这是**最能体现你理解状态机**的一段。

**★ 关键点**

1. 表达式用一条字符串保存（`"12.5+3*"`），每次按键后都重算一次"预览结果"，所以按完 `1 + 2` 就已经显示 `3`，不必等按等号
2. 输入运算符时如果末尾已经是运算符，直接**替换**而不是追加（避免出现 `5+×`）
3. 按过等号后再按数字 → `reset()` 开新算式；再按运算符 → 在结果上接着算

```java
/** 输入数字，"0"~"9" 或 "00" */
public void inputDigit(String digits) {
    if (justEvaluated) {
        reset();                       // ★ 等号后按数字 = 开新算式
    }
    int start = currentNumberStart();
    String current = expression.substring(start);
    if ("0".equals(current)) {         // ★ 前导 0 直接替换，避免出现 007
        if (digits.startsWith("0")) {
            return;
        }
        expression.setLength(start);
        current = "";
    }
    if (current.length() + digits.length() > MAX_NUMBER_LENGTH
            || expression.length() + digits.length() > MAX_EXPRESSION_LENGTH) {
        return;
    }
    expression.append(digits);
    refresh();
}

/** 输入运算符：+ - * / */
public void inputOperator(char operator) {
    if (error) {
        reset();
    }
    justEvaluated = false;
    int length = expression.length();
    if (length == 0) {                 // ★ 空表达式只允许减号开头（负数）
        if (operator == '-') {
            expression.append('-');
        }
        refresh();
        return;
    }
    if (expression.charAt(length - 1) == '.') {
        expression.append('0');
        length++;
    }
    if (isOperator(expression.charAt(length - 1))) {
        char lastOperator = expression.charAt(length - 1);
        if (length == 1 && lastOperator == '-') {
            return;
        }
        if (operator == '-' && (lastOperator == '*' || lastOperator == '/')) {
            expression.append('-');    // ★ 支持 5×−3 这种写法
        } else {
            expression.setCharAt(length - 1, operator);  // ★ 替换而不是追加
        }
    } else {
        expression.append(operator);
    }
    refresh();
}

/** 每次按键后重算预览结果 */
private void refresh() {
    String target = evaluableExpression();
    if (target.isEmpty()) {
        resultText = "0";
        error = false;
        return;
    }
    try {
        resultText = format(ExpressionEvaluator.evaluate(target));
        error = false;
    } catch (RuntimeException e) {
        resultText = ERROR_TEXT;       // ★ 除以 0 → 显示"错误"
        error = true;
    }
}

/** 去掉末尾悬空的运算符和小数点才能求值：1+2× → 1+2 */
private String evaluableExpression() {
    int end = expression.length();
    while (end > 0) {
        char c = expression.charAt(end - 1);
        if (c == '.' || isOperator(c)) {
            end--;
        } else {
            break;
        }
    }
    return expression.substring(0, end);
}
```

> 完整文件里还有 `inputPercent()`（当前数 ÷100）、`backspace()`、`equals()`、`format()`（去尾零、超长按 10 位有效数字舍入）和 `restore()`（转屏恢复现场），报告里挑上面这几个方法就够。

## 程序4：表达式求值 `ExpressionEvaluator.java`

**为什么是核心**：这是"运算"的实核。老师通常会问"你怎么保证先乘除后加减？"——答案是递归下降，这段代码要贴。**另外必须提一句：Android 没有 `ScriptEngine`，所以不能像 Java SE 那样用脚本引擎，只能自己写。**

**★ 关键点**

1. 文法：`expr := term (('+'|'-') term)*`，`term := factor (('*'|'/') factor)*` —— 语法层就把优先级定死了
2. 用 `BigDecimal` 而不是 `double`：`0.1+0.2` 必须显示 `0.3`，不能是 `0.30000000000000004`
3. `BigDecimal.divide` 必须指定 scale 和 `RoundingMode`，否则算 `1/3` 直接抛 `ArithmeticException`

```java
/** 词法分析：把 "12.5+3*4" 切成 [12.5, +, 3, *, 4] */
private static List<String> tokenize(String expression) {
    List<String> result = new ArrayList<>();
    int index = 0;
    while (index < expression.length()) {
        char c = expression.charAt(index);
        if (Character.isDigit(c) || c == '.') {
            int start = index;
            while (index < expression.length()) {
                char n = expression.charAt(index);
                if (!Character.isDigit(n) && n != '.') {
                    break;
                }
                index++;
            }
            result.add(expression.substring(start, index));
        } else if (isOperator(c)) {
            result.add(String.valueOf(c));
            index++;
        } else {
            throw new IllegalArgumentException("非法字符: " + c);
        }
    }
    return result;
}

/** 加法/减法：优先级最低，所以放在最外层 */
private BigDecimal parseExpression() {
    BigDecimal value = parseTerm();
    while (true) {
        String token = peek();
        if ("+".equals(token)) {
            pos++;
            value = value.add(parseTerm());
        } else if ("-".equals(token)) {
            pos++;
            value = value.subtract(parseTerm());
        } else {
            return value;
        }
    }
}

/** 乘法/除法：先算这一层，就实现了"先乘除后加减" */
private BigDecimal parseTerm() {
    BigDecimal value = parseFactor();
    while (true) {
        String token = peek();
        if ("*".equals(token)) {
            pos++;
            value = value.multiply(parseFactor());
        } else if ("/".equals(token)) {
            pos++;
            BigDecimal divisor = parseFactor();
            if (divisor.compareTo(BigDecimal.ZERO) == 0) {
                throw new ArithmeticException("除数不能为 0");   // ★ 除零
            }
            // ★ 必须给精度，否则 1/3 会抛 ArithmeticException
            value = value.divide(divisor, 19, RoundingMode.HALF_UP);
        } else {
            return value;
        }
    }
}

/** 数字，以及正负号 */
private BigDecimal parseFactor() {
    String token = peek();
    if (token == null) {
        throw new IllegalArgumentException("表达式不完整");
    }
    if ("-".equals(token)) {
        pos++;
        return parseFactor().negate();
    }
    if ("+".equals(token)) {
        pos++;
        return parseFactor();
    }
    if (isOperator(token.charAt(0))) {
        throw new IllegalArgumentException("运算符位置非法");
    }
    pos++;
    return new BigDecimal(token);
}
```

## 程序5：按键监听与结果显示 `MainActivity.java`

**为什么放最后**：它把前面四个部分串起来，正好回答"界面和逻辑是怎么连上的"。

**★ 关键点**：20 个按键**没有写 20 个监听器**，而是每个键在 XML 里用 `android:tag` 标注语义（`"7"`、`"+"`、`"C"`、`"DEL"`），代码里遍历 id 数组注册同一个 `OnClickListener`，再用 `switch(tag)` 分发——这是这段代码的亮点，报告里一定要写。

```java
/** 键盘全部按键，顺序与布局一致：5 行 × 4 列 */
private static final int[] KEY_IDS = {
        R.id.key_c, R.id.key_del, R.id.key_percent, R.id.key_div,
        R.id.key_7, R.id.key_8, R.id.key_9, R.id.key_mul,
        R.id.key_4, R.id.key_5, R.id.key_6, R.id.key_sub,
        R.id.key_1, R.id.key_2, R.id.key_3, R.id.key_add,
        R.id.key_00, R.id.key_0, R.id.key_dot, R.id.key_eq
};

@Override
protected void onCreate(Bundle savedInstanceState) {
    super.onCreate(savedInstanceState);
    setContentView(R.layout.activity_main);

    expressionView = findViewById(R.id.tv_expression);
    resultView = findViewById(R.id.tv_result);

    // ★ 20 个按键共用一个监听器
    View.OnClickListener listener = new View.OnClickListener() {
        @Override
        public void onClick(View view) {
            view.performHapticFeedback(HapticFeedbackConstants.KEYBOARD_TAP); // 触感反馈
            dispatchKey(view);
            render();
        }
    };
    for (int id : KEY_IDS) {
        findViewById(id).setOnClickListener(listener);
    }
    render();
}

/** 根据按键的 tag 分发到引擎 */
private void dispatchKey(View view) {
    Object tag = view.getTag();
    if (!(tag instanceof String)) {
        return;
    }
    String key = (String) tag;
    switch (key) {
        case "C":
            engine.clear();
            break;
        case "DEL":
            engine.backspace();
            break;
        case "%":
            engine.inputPercent();
            break;
        case "=":
            engine.equals();
            break;
        case ".":
            engine.inputDot();
            break;
        case "+":
        case "-":
        case "*":
        case "/":
            engine.inputOperator(key.charAt(0));
            break;
        default:
            engine.inputDigit(key);      // 0~9 和 "00"
            break;
    }
}

/** 把引擎状态渲染到显示区 */
private void render() {
    expressionView.setText(engine.getExpressionText());
    resultView.setText(engine.getResultText());
    resultView.setTextColor(ContextCompat.getColor(this,
            engine.isError() ? R.color.text_error : R.color.text_primary));
}
```

## 附：报告正文可以直接套的几句话

- **界面**：界面使用 `TableLayout` 组织键盘区，5 个 `TableRow` 对应 5 行，每行 4 个按键通过 `layout_width=0dp + layout_weight=1` 与 `stretchColumns="*"` 实现四列等宽；按键背景为圆角半径 `1000dp` 的胶囊形 drawable，配合 `ripple` 提供点击反馈。
- **输入**：按键输入由一个状态机（`CalcEngine`）统一维护，界面只负责把按键交给引擎、再把引擎的文本渲染回去，做到界面与运算逻辑分离，便于单元测试。
- **运算**：运算采用递归下降法实现：`parseExpression` 处理加减，`parseTerm` 处理乘除，由于乘除在更内层先被归约，因此天然满足"先乘除后加减"。数值统一使用 `BigDecimal`，避免二进制浮点误差（如 `0.1+0.2` 得到 `0.3`）。
- **异常处理**：除数为 0 时抛出 `ArithmeticException`，界面捕获后在结果区显示红色"错误"，按 `C` 即可恢复。
