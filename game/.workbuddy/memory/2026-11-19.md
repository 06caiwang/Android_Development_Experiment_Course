## Android 实验：坦克大战「我同意游戏条款」

- 工程：`D:/AndoridShiyan/game`，Material3 + Java，minSdk 24，三页面跳转：MainActivity(activity_splash) → TermsActivity(activity_terms) → GameActivity(activity_game)。
- 条款页核心：ConstraintLayout 骨架（卡片 0dp 高度上下约束 + ScrollView），两个 MaterialCheckBox 共用一个 OnCheckedChangeListener，全勾选才 `setEnabled(true)`。
- 配色：bg #080D16 / surface #101A2B / 主色橙 #FFB020 / 辅色青 #38E1FF；背景 drawable 用 layer-list 叠加线性渐变 + 径向光晕。
- 坑：Android strings.xml 会把源码换行压缩成空格，条款段落必须用 `\n` 显式换行；style 名带点（如 `Text.Game.Xxx`）会隐式继承 `Text.Game`，不存在则编译报错。
- 验证方式：模拟器 Pixel_3a_API_36（1080×2220），`adb shell uiautomator dump` 取控件 bounds 用于截图标注；`.tools/Annotate.java` 画红框+序号，`.tools/CodeShot.java` 把代码渲染成深色编辑器截图（中文注释回退微软雅黑，Consolas 无双字节字形）。
